## Spec Reference

**App:** Cosmos — an interactive explorer for 12 canonical astronomical objects (planets, moons, stars, nebulae, galaxies, black hole, exoplanet system). Cinematic dark-sky mood, awe-focused. 12 fixed objects with real facts, stats, "did you know" facts. No authentication, no accounts. Capabilities: browse/filter by category or search name, view object details, see object-of-the-day (deterministic per date), anonymous "chills" reaction count (server-persisted, no login required). Render the cosmos with CSS/SVG/gradients/procedural visuals; no real photography required. Backend: self-contained, local SQLite only, public API endpoints for catalog and reactions. Local dev only—no deployment this run.
